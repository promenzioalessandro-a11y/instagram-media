# Registro dei controlli

Questo file tiene SOLO il diario dei controlli delle 9:00 e delle 19:00, in forma condensata.
Regole, coda, pubblicato e compiti stanno in sistema/stato.md e non vanno mai copiati qui.
Motivo del file (deciso il 07/11): il tool di scrittura rimanda il file per intero a ogni commit,
quindi un diario che cresce ogni giorno dentro stato.md fa costare la scrittura piu' di quanto valga.
Qui il commit quotidiano e' piccolo. Vale la stessa regola del 03/11: per esteso solo gli ultimi
sette giorni e le giornate in cui Alessandro ha detto o deciso qualcosa, il resto condensato per periodo.
